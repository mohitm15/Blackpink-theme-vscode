# BLACKPINK — Midnight Stage 🖤💗

**A BLACKPINK-inspired dark colour theme for Visual Studio Code.** Deep-black and plum surfaces meet rose-pink accents, lavender functions, and flashes of neon cyan. Designed for a distinctive workspace without losing the syntax cues you need to code.

**Theme:** `BLACKPINK — Midnight Stage` · **Version:** `1.0.0` · **Author:** **Mohit Maroliya**

> **BLACK. PINK. CODE.** A fan-made theme inspired by the contrast and stage aesthetics of BLACKPINK eras such as *SQUARE UP*, *BORN PINK*, and *DEADLINE*. This project is unofficial and does not include official album artwork.

## ✨ Features

- **True midnight aesthetic:** near-black editor (`#0F0011`), deep-plum panels, soft rose text, and vivid pink accents.
- **Consistent workbench styling:** editor tabs, Activity Bar, Explorer, breadcrumbs, menus, command UI, notifications, search, lists, scrollbars, minimap, and status bar.
- **Designed for code:** differentiated keywords, variables, properties, functions, methods, strings, numbers, and operators.
- **TextMate + semantic highlighting:** syntax-scope fallbacks alongside semantic token colours when supported by your language tooling.
- **Language-focused refinements:** rules for JavaScript, TypeScript, JSX/TSX, Python, Java, HTML, CSS, JSON/JSONC, Markdown, and additional languages.
- **Readable configuration:** commented sections explain UI colours, TextMate syntax scopes, and semantic token mappings.

## 💻 Language support

The theme supplies **TextMate syntax rules**, with **semantic-token colours** for supported symbol types. It includes targeted configuration for:

| Language / family | Highlights |
| --- | --- |
| JavaScript | Variables, functions, methods, operators, keywords, template strings |
| TypeScript / React TSX | Type information, JSX elements/attributes, methods, templates |
| Python | Variables, decorators, functions, arguments, docstrings |
| Java | Classes, interfaces, annotations, parameters, methods, properties |
| HTML / CSS and related stylesheets | Tags, attributes, selectors, properties and values |
| JSON / JSONC | Nested keys, numbers, booleans and comments |
| Markdown | Headings, links, emphasis, lists and code blocks |
| C / C++, PHP and others | Additional TextMate scopes and shared token colours |

**Note:** The theme changes colours; it does not install language grammars, debugging tools, IntelliSense, or language servers. The appearance of a token depends on the installed language extensions and the scopes/semantic tokens they provide.

## 🚀 Installation

### Install locally from this repository (available now)

1. Clone or download this repository, preserving the folder structure below.
2. Copy the extension folder into your local VS Code extensions directory:

   | Operating system | Extensions directory |
   | --- | --- |
   | Windows | `%USERPROFILE%\.vscode\extensions\` |
   | macOS | `~/.vscode/extensions/` |
   | Linux | `~/.vscode/extensions/` |

3. Restart VS Code, or run **Developer: Reload Window** from the Command Palette.
4. Open the colour-theme picker: **Ctrl+K, Ctrl+T** (Windows/Linux) or **Cmd+K, Cmd+T** (macOS).
5. Select **BLACKPINK — Midnight Stage**.

For a quick Java preview, open [`examples/BlackpinkThemePreview.java`](examples/BlackpinkThemePreview.java) and use a Java language extension if you want semantic-token highlighting.

## 🛠 Customize it

Open VS Code `settings.json` and override individual theme colours without editing the extension itself:

```jsonc
{
  "workbench.colorCustomizations": {
    "[BLACKPINK — Midnight Stage]": {
      "editorCursor.foreground": "#FF80BA",
      "editor.lineHighlightBackground": "#24001E"
    }
  }
}
```

The theme file includes `//` explanatory comments, so it is **JSON with Comments (JSONC)** rather than strict JSON. Keep the extension file at `themes/BLACKPINK-Midnight-Stage-color-theme.json` as referenced by `package.json`.

To diagnose colour differences, run **Developer: Inspect Editor Tokens and Scopes** from the Command Palette. It helps identify which TextMate or semantic token rule is responsible.

## ❓ Troubleshooting

**The theme does not appear in the picker.** Verify that `package.json` is at the root of the installed extension directory, not nested under an extra ZIP folder. Reload VS Code.

**Java or TypeScript colours look different from the screenshots.** Syntax scopes and semantic tokens depend on your installed language tooling. Enable the appropriate language extension, reopen the sample file, and inspect its tokens.

**My screenshot placeholder is not showing an image.** This is intentional. Save the image to its suggested path, remove the corresponding `<!-- ... -->` wrapping the Markdown image, and delete the visible placeholder caption.

**The theme file fails in a strict JSON parser.** The comments are valid for the VS Code colour-theme format but not strict JSON. Use a JSONC-aware parser or strip comments for tools requiring strict JSON.
